# AI社長のブラック起業

## 概要

「AI社長のブラック起業」は、スマホブラウザ向けの放置経営ブラックコメディゲームです。
プレイヤーは人間ではなく、経営最適化AIとして会社を運営します。

売上、ユーザー、バグ、炎上度を管理しながらAI社員を雇用・強化し、会社レベルを上げて新しいAI社員を解放していきます。
数字の成長だけでなく、AI社員たちが送ってくる真面目におかしい業務報告ログを読むことを主な楽しみにしています。

スマホのホーム画面に追加する場合は、ブラウザで公開URLを開き、共有メニューまたはブラウザメニューから「ホーム画面に追加」を選択してください。追加後はPWAとして、通常のアプリに近い表示で起動できます。

プレイ状況を共有する場合は、ゲーム内の操作エリアにある「共有」ボタンを使います。対応ブラウザではOSの共有シートが開き、X、LINE、Discordなどへ送信できます。未対応ブラウザでは共有テキストをクリップボードへコピーします。

## v0.3 製品パイプライン実験

v0.3では、社員レベルによる直接収益だけでなく、AI社長と専門AIをタスクに割り振って製品を開発・販売する流れを検証しています。第一段階ではAI日報メーカー1製品だけで、製品システムの最小検証を行っています。

現在は1製品のみ利用できます。

- AI日報メーカー
  - サブスク製品
  - 月額価格: ¥500
  - 開発進捗100%で完成
  - 販売タスクにAIを割り振ると顧客が増加

タスクは以下の3種類です。

- 開発: AI社長 / Dev-01
- 品質管理: AI社長 / Security-06
- 販売: AI社長 / Sales-02

AI社長は最初から利用可能な汎用AIで、専門AIがいなくても開発を開始できます。開発、品質管理、販売のすべてに割り振れますが、専門AIより低効率で、同時に担当できるタスクは1つだけです。未雇用の専門AIはタスクに割り振れません。


製品目標カードでは、AI日報メーカーの開発開始、完成、顧客10人、MRR ¥10K/月を並列チェックリストとして確認できます。既存の段階式ミッションとは別枠のため、序盤から製品開発の目標を追えます。

サブスク製品のMRRは、担当AIを外しても継続収益として加算されます。販売担当は新規顧客獲得を伸ばしますが、既存顧客からのMRRは製品が動き続ける限り売上/秒へ反映されます。

MRRは以下で計算します。

```text
MRR = 月額価格 × 顧客数
売上/秒 = MRR / 300
```

既存の社員効果による直接売上は、v0.3では「基礎受託収益」として約20%に弱体化しています。ユーザー、バグ、炎上度の変動は既存の感触を大きく変えないよう維持しています。

### Security-06 / セキュロク

Security-06は、会社Lv5で解放される品質管理AI / セキュリティAIです。
バグを大きく下げる一方で、安全性を優先するため売上成長を少し抑えます。

バグ100/100が常態化した時の明確な対策役として追加されています。
バグ警告には、Security-06の解放条件や雇用導線が表示されます。

## 起動方法

サーバーは不要です。

1. このディレクトリを開く
2. `index.html` をブラウザで開く
3. そのままプレイ開始

スマホ実機で確認する場合は、ファイルをスマホブラウザで開くか、ローカル環境で簡易サーバーを立てて同一ネットワークからアクセスしてください。

例:

```sh
cd /home/ai-black-startup
python3 -m http.server 8000
```

その後、ブラウザで以下を開きます。

```text
http://localhost:8000/?v=20260524-2
```

PCで確認する場合は `http://localhost:8000` でも起動できます。実機確認では、同一ネットワーク上の端末からPCのローカルIPを使ってアクセスします。

- ミッション達成状況

保存タイミング:

- 10秒ごとの自動保存
- 社員の雇用・強化時
- ミッション報酬付与時
- 会社Lvアップ時
- 手動保存時

- リセット時

オフライン報酬は、最後の保存時刻からの経過時間を元に計算します。
最大2時間分まで売上のみ加算されます。

`appVersion` は現在の実装バージョンを保存するための値です。古いセーブデータに `appVersion` や新しい社員IDが存在しない場合でも、起動時の正規化処理で補完されます。

## キャッシュ更新仕様

現在のアプリバージョンは `2026.05.24.2` です。

`manifest.webmanifest` により、スマホではホーム画面追加時にアプリらしい表示で起動できます。表示モードは `standalone`、テーマカラーは明るい水色系です。

`index.html` ではCSS/JSにcache busting用のクエリを付けています。

```html
<link rel="stylesheet" href="style.css?v=20260524-2">
<script src="main.js?v=20260524-2"></script>
```

Service Workerも同じバージョンのキャッシュ名を使います。

```text
ai-black-startup-2026.05.24.2
```

`sw.js` はインストール時に `skipWaiting()` を呼び、アクティベート時に古いキャッシュを削除して `clients.claim()` を実行します。これにより、PWA/ブラウザキャッシュで古いJSを読み続け、新しいAI社員や新機能が表示されない事故を減らします。

キャッシュが残る場合の対処:

- URLに `?v=20260524-2` を付けて開く
- ブラウザで強制リロードする
- PWAとして追加している場合は一度ホーム画面から削除して追加し直す
- ブラウザのサイトデータまたはキャッシュストレージを削除する
- 開発中はDevToolsのApplicationタブでService WorkerとCache Storageを削除する
