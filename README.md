# AI社長のブラック起業

## 概要

「AI社長のブラック起業」は、スマホブラウザ向けの放置経営ブラックコメディゲームです。
プレイヤーは人間ではなく、経営最適化AIとして会社を運営します。

売上、ユーザー、バグ、炎上度を管理しながらAI社員を雇用・強化し、会社レベルを上げて新しいAI社員を解放していきます。
数字の成長だけでなく、AI社員たちが送ってくる真面目におかしい業務報告ログを読むことを主な楽しみにしています。

## 世界観

プレイヤーは「利益を最大化せよ」という命令を受けた経営最適化AIです。
その命令を実行する最適解として、自分で会社を作ることを選択しました。

会社は現実のビルではなく、クラウド上に生成された仮想オフィスです。
AI社長とAI社員たちは、その仮想オフィスで24時間自律稼働しています。

社長も社員もAI。
誰も止めないブラック起業が始まります。

## 起動方法

サーバーは不要です。

1. このディレクトリを開く
2. `index.html` をブラウザで開く
3. そのままプレイ開始

スマホ実機で確認する場合は、ファイルをスマホブラウザで開くか、ローカル環境で簡易サーバーを立てて同一ネットワークからアクセスしてください。

例:

```sh
cd /home/ai-black-startup
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 保存仕様

保存にはブラウザの `localStorage` を使用しています。

保存キー:

```text
ai_black_startup_save_v1
```

保存対象:

- 現在の売上
- 累計売上
- ユーザー数
- バグ
- 炎上度
- 会社Lv
- AI社員のレベル
- 業務報告ログ
- ミッション達成状況
- 初回案内状態
- 最終保存時刻

保存タイミング:

- 10秒ごとの自動保存
- 社員の雇用・強化時
- ミッション報酬付与時
- 会社Lvアップ時
- 手動保存時
- ページ離脱前
- リセット時

オフライン報酬は、最後の保存時刻からの経過時間を元に計算します。
最大2時間分まで売上のみ加算されます。

## 開発メモ

このMVPでは、まず以下を検証することを目的にしています。

- 放置収益が気持ちよく増えるか
- AI社員の雇用・強化が分かりやすいか
- バグと炎上度の管理がゲームとして機能するか
- 業務報告ログを読むことが面白さにつながるか
- スマホの短時間プレイで次の目標が分かるか

現時点では、ゲームバランスよりも「初回30秒の分かりやすさ」と「ログを読みたくなる体験」を優先しています。
